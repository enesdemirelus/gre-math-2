# Official ETS sources

The PDFs are not committed (ETS copyright). Download them into this folder to run reviews.

| File | URL |
|---|---|
| math-review.pdf (GRE Math Review, © 2024 ETS) | https://www.ets.org/content/dam/ets-org/pdfs/gre/gre-math-review.pdf |
| conventions.pdf (GRE Math Conventions, © 2024 ETS) | https://www.ets.org/content/dam/ets-org/pdfs/gre/gre-math-conventions.pdf |
| qr-strategies.pdf (Quantitative Reasoning Strategies, official sample questions with explanations) | https://www.ets.org/content/dam/ets-org/pdfs/gre/quantitative-reasoning-strategies.pdf |
| Quantitative Reasoning overview (question types, content areas) | https://www.ets.org/gre/test-takers/general-test/prepare/content/quantitative-reasoning.html |

Text versions: `pdftotext -layout <file>.pdf <file>.txt`. Symbol fonts do not extract cleanly; check the PDF page image when a formula looks garbled.

Page numbers in `notes/` are the printed page numbers. In `math-review.pdf`, PDF page = printed page + 1; in `conventions.pdf` they match.
